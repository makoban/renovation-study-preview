# Renovation Study — 1枚の図面から6案を比較

販売図面の公開見本1枚をもとに、AIで作成した完成予想と簡易2D・3Dを比較するデモです。現在は1件の見本図面について、生成済みの6案をブラウザで比較できます。

## 公開URL

https://makoban.github.io/renovation-study-preview/

GitHub Pagesで公開しています。ログインは不要で、URLを知る方が閲覧できます。noindexとrobots.txtは検索登録を抑制する指定であり、アクセス制限ではありません。

## 比較できること

- 壁を残して3LDKを維持するタイプと、洋室を取り込んで大きなLDKの2LDKにするタイプ。
- 各タイプにモダン・ラグジュアリー・和モダンの3デザイン。合計6つの完成予想。
- 2Dの家具配置と、ドラッグで回転・拡大できる簡易3Dモデル。
- 主要家具の公式写真・商品名・型番・寸法・参考価格・公式リンク。図面番号と商品カードが連動。
- 原本図面の表示・拡大と、出典リンク。

任意図面の入力から6案の生成までを一括実行する機能は今後の開発対象です。この公開ページは生成済みの見本を比較する静的デモです。

## 使用した原本図面

HILLSTON / GMC販売図面「中古マンション」B型の公開デザイン見本です。実際の販売物件・改修実績の案内ではありません。

- 出典ページ：https://www.hillston.co.jp/gmc-maisoku/works/mansion/
- 原本画像： https://makoban.github.io/renovation-study-preview/assets/v2/hillston-original.jpg
- 出典元の画像：https://www.hillston.co.jp/gmc-maisoku/wp-content/uploads/sites/4/2021/09/マンションB_地図有_ブラウン系.jpg

原本画像は未加工で掲載し、表示用サムネイルだけ縮小しています。図面・家具写真の権利は各権利者に帰属します。

## 寸法・法規・完成予想について

寸法線のない部分は仮定して作図しています。外形7.6×13m・天井高2.5mは作図上の仮定で、実測値ではありません。22.8帖相当は元図のLD12.5帖・洋室7帖・K3.3帖の単純合算で、改修後の設計面積ではありません。

柱型・外壁・窓・水回りの位置を残す想定で、撤去検討箇所と、構造・建築法規・管理規約などの確認ポイントを表示しています。構造調査や法令適合判定は実施していません。壁の撤去可否や適法性は、実物件の図面・現地調査と建築士等による確認が必要です。

完成予想は原本・家具配置図・公式商品写真を参照したAI画像です。家具の細部や建具、見え方には実物との差があります。3D家具は公式の外形寸法を使った簡略形状です。椅子・照明・ラグ等は参考表現で商品未指定。商品情報確認日2026-10-28。
